# Web Controle de Finanças — Plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Front Next.js com login/cadastro, lista e formulário de lançamentos e dashboard mensal, seguindo o canvas aprovado.

**Architecture:** Next 16 App Router. O JWT fica no cookie httpOnly `sessao`; Server Components e Server Actions chamam
a API Nest no servidor com `Authorization: Bearer`. O navegador nunca fala com a API. Filtros da lista rodam no cliente.

**Tech Stack:** Node 22.12.0, Next 16, React, TypeScript, Tailwind CSS, Vitest 5.

**Spec:** `../controle-financas/docs/superpowers/specs/2026-11-24-controle-financas-design.md`
(GitHub: `gsubp/controle-financas`, branch `develop`). Canvas: https://claude.ai/artifact/15s8x8yUzXroth3xreTW4k

## Global Constraints

- Todo comando `npm`/`npx` roda na raiz do repo depois de `source ~/.nvm/nvm.sh && nvm use` (`.nvmrc` = `22.12.0`).
- Dependências: as do `create-next-app@16` + `vitest@5` (dev). Nada mais — sem lib de gráfico, formulário, estado, datas ou HTTP.
- Next 16: `params`/`searchParams` são `Promise`, `cookies()` é assíncrono, o middleware chama-se `src/proxy.ts`
  (se a versão instalada ainda usar `middleware.ts`, usar esse nome).
- Cores (tokens Tailwind em `globals.css`): `fundo #F5F6F4`, `superficie #FFFFFF`, `tinta #16181D`, `suave #5B616E`,
  `borda #E2E4E7`, `receita #2B5FD9`, `receita-texto #1F4FB8`, `receita-fundo #E8EEFB`, `despesa #D9701F`,
  `despesa-texto #9A3F08`, `despesa-fundo #FBEDE3`. Fontes: Inter (texto, `font-sans`) e Space Grotesk (`font-display`).
- `<html lang="pt-BR">`; toda a cópia em português; valores com `font-variant-numeric: tabular-nums`.
- Acessibilidade: `<button>`/`<a>` reais, todo `<input>`/`<select>` com `<label>`, `aria-label` em botão só com ícone,
  alvos de toque ≥ 44 px, ícones SVG inline com `aria-hidden="true"`.
- Cookie `sessao`: `httpOnly`, `sameSite: 'lax'`, `secure` quando `NODE_ENV === 'production'`, `maxAge` 7 dias, `path: '/'`.
- `API_URL` (env) com padrão `http://localhost:3333`. `.env*` fora do git, exceto `.env.example`.
- Em Server Actions, `catch` trata só `ErroApi`; qualquer outro erro é relançado (`redirect()` do Next funciona lançando).
- Commits: `tipo: descrição` em português, terminando com `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Verificação manual exige a API rodando: `cd ../controle-financas && npm run start:dev` (porta 3333).

## Review Focus

- `formatarData('2026-11-01')` mostra `01/11/2026` em America/Sao_Paulo — nunca `new Date('YYYY-MM-DD')` para exibir (Task 1).
- Valor digitado em pt-BR (`1.234,56`, `1234,5`, `R$ 10,00`) vira centavos certos; lixo vira erro no formulário (Tasks 1 e 3).
- Às 23h de 30/11 em São Paulo (02h UTC de 01/12) o mês atual ainda é novembro (Task 1).
- `?mes=abc` ou `?mes=2026-13` cai no mês atual em vez de página de erro (Task 1, usado nas Tasks 3 e 4).
- Token vencido/forjado leva a `/login` com o cookie apagado, sem loop de redirecionamento (Task 2).
